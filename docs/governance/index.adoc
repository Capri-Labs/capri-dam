This guide defines **who decides what, how, and by which rules** for the Capri DAM
platform and the digital assets it manages. Where the
link:../architecture/[Architecture Guide] explains *how the system is built* and the
link:../developer-guide/[Developer Guide] explains *how to build with it*, this guide
explains *how the platform and its content are governed* — ownership, decision rights,
data classification, retention, change control, vendor oversight, and compliance
mapping.

It complements the security posture described in the
link:../security/[Security Guide], which covers *how* the platform protects data;
this guide covers *who is accountable* for what happens to that data and *under what
policy*.
