This guide documents **how** Capri DAM technically protects the platform and
the data it manages — authentication, authorization, encryption, secrets
handling, network hardening, application security testing, vulnerability
management, and incident response. It complements the
link:../governance/[Governance Guide], which covers *who* is accountable for
platform and content decisions and *under what policy*; this guide covers the
technical controls that make those policies enforceable.
